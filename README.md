# ad-video-classifier

광고 비디오를 제작 형식 태그로 분류하는 멀티모달 모델입니다. VLM 백본에 3D CNN 시계열
프레임 브랜치를 결합한 이중 구조로, 정지 프레임만으로는 경계가 흐려지는 형식을 카메라
움직임과 컷 전환 패턴으로 구분합니다.

과학기술정보통신부와 정보통신산업진흥원의 첨단 GPU 활용 지원 사업 25-1차 지원으로
개발했습니다.

## 분류 클래스

제작 형식 3종입니다. 광고주가 실제로 선택할 수 있는 형식이 사내 역량에 따라 갈리기
때문에, 필요한 제작 역량이 낮은 순서로 배열했습니다.

| 클래스 | 판별 근거 | 필요 제작 역량 |
|---|---|---|
| UGC | 핸드헬드 흔들림 | 없음 |
| 모션 그래픽 | 키프레임 이징 패턴 | 영상 전문가 |
| 실사 | 안정된 카메라와 계획된 컷 전환 | 촬영팀 |

## 성능

학습에 사용하지 않은 광고 비디오 1,000편을 무작위 추출해 평가했습니다. 정답지는 실제
광고 집행 결과와 전문 레이블러가 검수한 태그 데이터입니다.

| 클래스 | 편수 | Precision | Recall | F1 | AP |
|---|---|---|---|---|---|
| UGC | 566 | 0.9484 | 0.9392 | 0.9438 | 0.9873 |
| 모션 그래픽 | 141 | 0.9318 | 0.8716 | 0.9007 | 0.9702 |
| 실사 | 293 | 0.8375 | 0.8792 | 0.8579 | 0.9390 |
| **Macro 평균** | **1,000** | **0.9059** | **0.8967** | **0.9008** | **0.9655** |

mAP는 클래스별 Average Precision의 Macro 평균입니다.

### Confusion Matrix

| 실제 / 예측 | UGC | 모션 그래픽 | 실사 |
|---|---|---|---|
| UGC | 532 | 1 | 34 |
| 모션 그래픽 | 2 | 123 | 16 |
| 실사 | 27 | 8 | 258 |

오분류 88편 가운데 UGC와 실사의 상호 오분류가 61편으로 69.3%를 차지합니다. 두 형식은
피사체와 화면 구성이 유사해 시계열 정보에 의존해 갈립니다. 모션 그래픽은 나머지 두
클래스와의 오분류가 각각 1편과 2편에 불과합니다.
